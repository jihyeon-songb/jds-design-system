# Input Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@jdsb/components`에 native 동작과 `sm`~`xl` 상태 스타일을 제공하는 접근 가능한 Input을 추가한다.

**Architecture:** Input은 native `<input>` 하나에 class와 stable data attribute만 추가한다. 기존 field 색상·focus·radius 토큰을 재사용하고 Input의 높이와 여백 토큰만 생성한다. Storybook은 기존 preview의 axe 구성으로 컴포넌트를 문서화한다.

**Tech Stack:** React 19, TypeScript 5, native CSS, Vitest, Testing Library, Storybook 10, pnpm workspace.

## Global Constraints

- native HTML과 표준 ARIA만 사용하고 외부 UI 라이브러리나 새 의존성을 추가하지 않는다.
- 공개 API에는 명시적 TypeScript 타입을 제공하고 ref 및 적용 가능한 native input 속성을 전달한다. native 숫자 `size` 속성은 JDSB 문자열 `size` API와 충돌하므로 제외한다.
- `InputSize`는 `"sm" | "md" | "lg" | "xl"`이며 기본값은 `"md"`다.
- CSS에는 시각 값 리터럴을 쓰지 않고 `--jdsb-*` 토큰만 사용한다.
- `invalid`일 때만 `aria-invalid="true"`를 설정하고, 그렇지 않으면 소비자가 제공한 `aria-invalid`를 보존한다. `data-state` 우선순위는 disabled, readonly, invalid, idle이다.
- 값 변환·입력 제한·아이콘 슬롯·type별 동작·FormField API를 추가하지 않는다.
- WCAG 2.2 AA를 기준으로 focus-visible, keyboard, forced-colors, reduced-motion을 지원한다.
- 완료 전 `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm lint`, Storybook build를 통과시킨다.

- [ ] **Step 3: Input CSS를 작성한다**

```css
.jdsb-input {
  background: var(--jdsb-color-field-background);
  border: var(--jdsb-size-border) solid var(--jdsb-color-field-border);
  border-radius: var(--jdsb-radius-control);
  color: var(--jdsb-color-field-foreground);
  font: inherit;
  height: var(--jdsb-size-control-input-md-height);
  padding-inline: var(--jdsb-space-input-inline);
}

.jdsb-input[data-size="sm"] { height: var(--jdsb-size-control-input-sm-height); }
.jdsb-input[data-size="lg"] { height: var(--jdsb-size-control-input-lg-height); }
.jdsb-input[data-size="xl"] { height: var(--jdsb-size-control-input-xl-height); }
.jdsb-input[data-state="invalid"] { border-color: var(--jdsb-color-field-invalid-border); }
.jdsb-input:focus-visible { outline: var(--jdsb-size-focus) solid var(--jdsb-color-focus-ring); outline-offset: var(--jdsb-size-focus); }
```

같은 파일에 disabled·readOnly를 제외한 hover, disabled opacity, readOnly border, reduced-motion, forced-colors selector를 추가한다. Input type별 브라우저 UI를 바꾸는 selector는 넣지 않는다.

- [ ] **Step 1: 실패하는 Input 테스트를 작성한다**

`packages/components/src/Input.test.tsx`에 다음 테스트를 작성한다.

```tsx
it("forwards the ref and native input props", () => {
  const ref = createRef<HTMLInputElement>()
  render(<Input ref={ref} aria-label="이메일" name="email" required type="email" />)

  expect(ref.current).toHaveAttribute("name", "email")
  expect(ref.current).toHaveAttribute("type", "email")
  expect(ref.current).toBeRequired()
})

it("preserves uncontrolled values", () => {
  render(<Input aria-label="이름" defaultValue="하나" />)
  const control = screen.getByRole("textbox", { name: "이름" })
  fireEvent.change(control, { target: { value: "둘" } })
  expect(control).toHaveValue("둘")
})

it("renders controlled values", () => {
  render(<Input aria-label="이름" value="셋" onChange={() => undefined} />)
  const control = screen.getByRole("textbox", { name: "이름" })
  expect(control).toHaveValue("셋")
})
```

별도 테스트에서 `invalid`의 `aria-invalid`, disabled·readOnly·invalid의 우선순위별 `data-state`, 모든 size의 `data-size`를 검증한다.

- [ ] **Step 3: 최소 Input 구현을 작성한다**

`packages/components/src/Input.tsx`에 다음 공개 타입을 작성한다.

```tsx
import { forwardRef, type ComponentPropsWithoutRef } from "react"

export type InputSize = "sm" | "md" | "lg" | "xl"

export type InputProps = Omit<ComponentPropsWithoutRef<"input">, "size"> & {
  size?: InputSize
  invalid?: boolean
}
```

`forwardRef<HTMLInputElement, InputProps>`로 `<input>` 하나를 렌더링한다. `className`은 `jdsb-input`과 공백으로 결합하고, `size="md"`, `invalid=false`를 기본값으로 둔다. `data-size`와 우선순위가 적용된 `data-state`를 설정하고 `invalid`일 때만 `aria-invalid="true"`를 강제한다. 그렇지 않으면 소비자가 제공한 `aria-invalid`를 보존한다. 나머지 props, `value`, `defaultValue`, `onChange`, `aria-describedby`는 수정하지 않고 input에 전달한다.

`packages/components/src/index.ts`에 다음 export를 추가하고 `packages/components/tsconfig.json` include 배열에 `src/Input.tsx`를 추가한다.

```ts
export { Input, type InputProps, type InputSize } from "./Input.js"
```
