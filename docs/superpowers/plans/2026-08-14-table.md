# Table Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@jdsb/components`에 native HTML 표의 의미와 속성을 보존하는 token 기반 `Table` 프리미티브를 추가한다.

**Architecture:** 각 public primitive는 대응하는 native table element를 렌더링하는 무상태 `forwardRef` 래퍼다. 상태·정렬·선택·반응형 wrapper는 만들지 않고, 기존 field semantic token으로 최소한의 표 스타일만 제공한다. 패키지 배럴과 CSS entry에 등록하고 Storybook에서 native 의미를 확인한다.

**Tech Stack:** TypeScript, React 19, `@jdsb/tokens` CSS custom properties, Vitest + Testing Library, Storybook + axe.

## Global Constraints

- 새 런타임·개발 의존성이나 Table 전용 token을 추가하지 않는다.
- `Table`, `TableCaption`, `TableHeader`, `TableBody`, `TableFooter`, `TableRow`, `TableHead`, `TableCell`과 각 props type을 명시적으로 export한다.
- 각 primitive는 대응하는 native element와 정확한 element ref를 `forwardRef`로 전달한다.
- native 속성, 이벤트, `className`을 보존한다. `TableHead`는 `scope`, `colSpan`, `rowSpan`, `abbr`를 변환하지 않는다.
- data state, sorting, filtering, selection, pagination, row click, horizontal-scroll wrapper, variant, size API를 추가하지 않는다.
- CSS는 `color.field.background`, `color.field.foreground`, `color.field.border`, `size.border`, `space.field.item` semantic token만 사용한다. 시각 값 리터럴을 쓰지 않는다.
- Table은 비상호작용 구조다. role, keyboard handler, `tabIndex`, focus style, animation, transition을 추가하지 않는다.
- 모든 Storybook Story는 기존 axe 검사 대상에 남긴다.

- [ ] **Step 3: Implement the native wrappers and token-only stylesheet**

Create `packages/components/src/data/Table.tsx` using one local class join helper and eight `forwardRef` exports.

```tsx
import { forwardRef, type ComponentPropsWithoutRef } from "react"

const classes = (base: string, className?: string) => [base, className].filter(Boolean).join(" ")

export type TableProps = ComponentPropsWithoutRef<"table">
export type TableCaptionProps = ComponentPropsWithoutRef<"caption">
export type TableHeaderProps = ComponentPropsWithoutRef<"thead">
export type TableBodyProps = ComponentPropsWithoutRef<"tbody">
export type TableFooterProps = ComponentPropsWithoutRef<"tfoot">
export type TableRowProps = ComponentPropsWithoutRef<"tr">
export type TableHeadProps = ComponentPropsWithoutRef<"th">
export type TableCellProps = ComponentPropsWithoutRef<"td">

export const Table = forwardRef<HTMLTableElement, TableProps>(function Table({ className, ...props }, ref) {
  return <table {...props} ref={ref} className={classes("jdsb-table", className)} />
})

export const TableCaption = forwardRef<HTMLTableCaptionElement, TableCaptionProps>(function TableCaption({ className, ...props }, ref) {
  return <caption {...props} ref={ref} className={classes("jdsb-table-caption", className)} />
})

export const TableHeader = forwardRef<HTMLTableSectionElement, TableHeaderProps>(function TableHeader({ className, ...props }, ref) {
  return <thead {...props} ref={ref} className={classes("jdsb-table-header", className)} />
})
```

Implement `TableBody` and `TableFooter` with `HTMLTableSectionElement`, `TableRow` with
`HTMLTableRowElement`, `TableHead` with `HTMLTableCellElement`, and `TableCell` with
`HTMLTableCellElement`, following the same spread/ref/class pattern. Do not add props beyond
the native types.

Create `packages/components/src/data/Table.css`.

```css
.jdsb-table {
  background: var(--jdsb-color-field-background);
  border-collapse: collapse;
  color: var(--jdsb-color-field-foreground);
}

.jdsb-table-head,
.jdsb-table-cell {
  border-block-end: var(--jdsb-size-border) solid var(--jdsb-color-field-border);
  padding: var(--jdsb-space-field-item);
  text-align: start;
}
```

Add explicit classes for `caption`, `header`, `body`, `footer`, and `row` even when their
stylesheet rules are empty; this gives consumers stable selectors without changing native
semantics. Add `Table` and every props type to `packages/components/src/index.ts`, add
`@import "./data/Table.css";` to `packages/components/src/index.css`, and add
`"src/data/Table.css"` to the `files` list in `packages/components/package.json`.
