# Alert 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**목표:** 페이지 흐름 안에서 오류와 일반 상태를 접근 가능하게 알리고 선택적으로 닫을 수 있는 `Alert`를 `@jds/components`에 추가한다.

**아키텍처:** `Alert`는 native div 하나를 root로 사용한다. `error`에는 `role="alert"`, 나머지 variant에는 `role="status"`를 고정하고 포커스를 이동하지 않는다. React는 `open`이 없을 때만 열린 상태를 관리하고, CSS는 token 기반 root·slot·close button 표현만 담당한다.

**기술 스택:** React 19, TypeScript, CSS custom properties, Vitest, Testing Library, Storybook 10.

## Global Constraints

- 외부 UI 라이브러리와 새 의존성을 추가하지 않는다.
- Alert는 portal, 자동 닫힘, queue, transition을 구현하지 않는다.
- `variant`는 `"info" | "success" | "warning" | "error"`이고 기본값은 `"info"`다.
- `dismissible` Alert는 접근 가능한 닫기 이름인 `closeLabel`을 반드시 받는다.
- `error`는 `role="alert"`, 나머지는 `role="status"`이며 포커스를 이동하지 않는다.
- 시각 값은 `@jds/tokens` CSS 변수만 사용한다.

- [ ] **3단계: 최소 구현을 작성한다**

```tsx
export type AlertVariant = "info" | "success" | "warning" | "error"

type AlertBaseProps = Omit<ComponentPropsWithoutRef<"div">, "role"> & {
  defaultOpen?: boolean
  onOpenChange?: (open: boolean) => void
  open?: boolean
  title?: ReactNode
  variant?: AlertVariant
}

export type AlertProps =
  | (AlertBaseProps & { dismissible?: false; closeLabel?: never })
  | (AlertBaseProps & { closeLabel: string; dismissible: true })
```

`Alert.tsx`에서 `forwardRef<HTMLDivElement, AlertProps>`를 사용한다. `open`이
undefined이면 `useState(defaultOpen)`으로 internal state를 초기화하며 defaultOpen의
기본값은 true다. effective open이 false이면 null을 반환한다. root role은 error일 때만
`"alert"`, 그렇지 않으면 `"status"`로 고정한다. title과 children은 각각
`data-slot="title"`, `data-slot="description"` wrapper로 렌더링한다.

it("closes an uncontrolled dismissible alert and reports the state change", async () => {
  const user = userEvent.setup()

- [ ] **3단계: token과 token-only CSS를 작성한다**

`color.alert.info|success|warning|error.{background,foreground,border}`를 추가한다.
info와 success는 기존 primary action 값, warning은 secondary action 값, error는
destructive action 값을 참조한다. `space.alert.inline`, `block`, `gap`, `close-gap`과
`size.control.alert-close` dimension token을 추가한다.

`Alert.css`는 `.jds-alert`과 `data-variant` selector, `data-slot` selector만 사용한다.
root의 background·foreground·border, padding·gap·radius를 token 변수로 적용한다.
close button은 최소 `--jds-size-control-alert-close` 크기, inherited color,
focus-visible `size.focus`/`color.focus.ring` outline을 사용한다. hardcoded 시각 값,
transition, custom keyframe을 추가하지 않는다. forced-colors에서는
`forced-color-adjust: auto`를 사용한다.

`index.ts`에 아래 export를 추가하고 `index.css`에 Alert.css import, package `files`에
Alert.css를 추가한다.

```ts
export { Alert, type AlertProps, type AlertVariant } from "./feedback/Alert.js"
```
