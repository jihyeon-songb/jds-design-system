# Badge 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**목표:** 다섯 semantic variant의 짧은 텍스트 상태를 표시하는 비상호작용 `Badge`를 `@jdsb/components`에 추가한다.

**아키텍처:** `Badge`는 native span 하나와 `data-variant`만 제공한다. 색상과 여백은 새 Badge component token으로만 표현하고, package entry와 CSS entry에서 public surface를 연결한다. 상태 변경 알림, 키보드 처리, 내부 state는 없다.

**기술 스택:** React 19, TypeScript, CSS custom properties, Vitest, Testing Library, Storybook 10.

## Global Constraints

- 외부 UI 라이브러리와 새 의존성을 추가하지 않는다.
- Badge는 native `<span>`이고 상호작용, live region, focus management, 내부 state를 구현하지 않는다.
- `variant`는 `"neutral" | "info" | "success" | "warning" | "error"`이고 기본값은 `"neutral"`다.
- Badge가 전달하는 상태는 children 텍스트로도 식별 가능해야 하며 dot-only 표현을 만들지 않는다.
- 시각 값은 `@jdsb/tokens` CSS 변수만 사용한다.

- [ ] **Step 3: Implement the minimum Badge component**

```tsx
import { forwardRef, type ComponentPropsWithoutRef } from "react"

export type BadgeVariant = "neutral" | "info" | "success" | "warning" | "error"

export type BadgeProps = ComponentPropsWithoutRef<"span"> & {
  variant?: BadgeVariant
}

export const Badge = forwardRef<HTMLSpanElement, BadgeProps>(function Badge(
  { className, variant = "neutral", ...props },
  ref
) {
  return (
    <span
      {...props}
      ref={ref}
      className={["jdsb-badge", className].filter(Boolean).join(" ")}
      data-variant={variant}
    />
  )
})
```

Do not destructure `children`: passing the remaining span props preserves children, aria attributes, role, and all other native span attributes. Do not add `role`, keyboard handlers, state, or focus behavior.
