# Tooltip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** focus와 hover에서 보조 정보를 표시하고 Escape·blur·pointer leave에서 닫히는 Tooltip을 제공한다.

**Architecture:** `Tooltip`은 positioned wrapper와 Context에서 open state, stable content ID, delay timer를 소유한다. `TooltipTrigger`는 단일 child를 clone해 ARIA와 handler를 합성하고, `TooltipContent`는 role·state·side를 가진 non-interactive `<span>`을 렌더링한다.

**Tech Stack:** React 19, TypeScript, CSS semantic token, Vitest, Testing Library, Storybook 10.

## Global Constraints

- `pnpm`만 사용하며 runtime dependency와 token을 추가하지 않는다.
- `Tooltip`, `TooltipTrigger`, `TooltipContent`만 export한다. Provider, controlled state, delay prop, Portal, arrow, animation, collision avoidance는 제외한다.
- Trigger는 DOM props를 전달하는 단일 React element여야 한다. Tooltip은 accessible name 또는 label을 대체하지 않는다.
- 표시 delay는 300ms다. blur, outside pointer leave, Escape는 즉시 닫는다.
- CSS의 색상·간격·반경은 `--jdsb-*` semantic token만 사용한다.
- Content는 `role="tooltip"`, Trigger는 merged `aria-describedby`를 사용한다. Content는 focusable 또는 interactive가 아니다.
- 단순 상태에는 `useMemo`/`useCallback`을 추가하지 않는다. timer와 DOM ref는 `useRef`로 관리한다.

```tsx
import { act, fireEvent, render, screen } from "@testing-library/react"
import { afterEach, beforeEach, expect, it, vi } from "vitest"

beforeEach(() => vi.useFakeTimers())
afterEach(() => vi.useRealTimers())

it("focus와 hover 뒤 300ms에 열고 blur에서 즉시 닫는다", () => {
  render(
    <Tooltip>
      <TooltipTrigger><button>도움말</button></TooltipTrigger>
      <TooltipContent>추가 정보를 표시합니다.</TooltipContent>
    </Tooltip>
  )
  const trigger = screen.getByRole("button", { name: "도움말" })
  const content = screen.getByRole("tooltip", { hidden: true })

  fireEvent.focus(trigger)
  expect(content).toHaveAttribute("data-state", "closed")
  act(() => vi.advanceTimersByTime(300))
  expect(content).toHaveAttribute("data-state", "open")
  expect(trigger).toHaveAttribute("aria-describedby", content.id)

  fireEvent.blur(trigger)
  expect(content).toHaveAttribute("data-state", "closed")
  expect(content).toHaveAttribute("hidden")
})

it("trigger와 content 사이 pointer 이동은 유지되고 Escape는 닫힌다", () => {
  render(
    <Tooltip>
      <TooltipTrigger><button>설명</button></TooltipTrigger>
      <TooltipContent>보조 설명</TooltipContent>
    </Tooltip>
  )
  const trigger = screen.getByRole("button", { name: "설명" })
  const content = screen.getByRole("tooltip", { hidden: true })

  trigger.focus()
  fireEvent.pointerEnter(trigger)
  act(() => vi.advanceTimersByTime(300))
  fireEvent.pointerLeave(trigger, { relatedTarget: content })
  expect(content).toHaveAttribute("data-state", "open")
  fireEvent.keyDown(trigger, { key: "Escape" })
  expect(content).toHaveAttribute("data-state", "closed")
  expect(trigger).toHaveFocus()
})
```

추가 cases: `aria-describedby="기존-설명"`에 Content ID를 한 번만 병합, `side="left"`, native click 유지, consumer `onKeyDown`의 Escape preventDefault, Context 밖 part Error, unmount timer cleanup, Trigger/Content ref와 native props forwarding.

- [ ] **Step 3: 최소 compound implementation을 작성한다**

```tsx
const OPEN_DELAY = 300

type TooltipContextValue = {
  contentId: string
  open: boolean
  closeNow: () => void
  openAfterDelay: () => void
  wrapperRef: RefObject<HTMLSpanElement | null>
}

export type TooltipSide = "top" | "right" | "bottom" | "left"
export type TooltipProps = ComponentPropsWithoutRef<"span"> & { children: ReactNode }
export type TooltipTriggerProps = { children: ReactElement }
export type TooltipContentProps = Omit<ComponentPropsWithoutRef<"span">, "id" | "role"> & {
  side?: TooltipSide
}

const [open, setOpen] = useState(false)
const timerRef = useRef<ReturnType<typeof setTimeout> | undefined>(undefined)

function closeNow(): void {
  if (timerRef.current !== undefined) clearTimeout(timerRef.current)
  timerRef.current = undefined
  setOpen(false)
}

function openAfterDelay(): void {
  if (open || timerRef.current !== undefined) return
  timerRef.current = setTimeout(() => {
    timerRef.current = undefined
    setOpen(true)
  }, OPEN_DELAY)
}
```

`Tooltip`은 `useId()`, wrapper ref, timer cleanup effect와 Context Provider를 가진
`<span className="jdsb-tooltip">`로 렌더링한다. forwarded ref는 callback ref에서
internal ref 다음 function/object ref에 전달한다.

`TooltipTrigger`는 `Children.only(children)`와 `cloneElement`를 사용한다. child
handler를 먼저 실행하고 prevent되지 않았을 때 focus/pointer enter는
`openAfterDelay()`, blur와 Escape는 `closeNow()`를 실행한다. pointer leave는
`wrapperRef.current?.contains(event.relatedTarget as Node)`가 false일 때만 닫는다.
기존 `aria-describedby`에 `contentId`를 중복 없이 공백 병합한다.

`TooltipContent`는 `id={contentId}`, `role="tooltip"`, `hidden={!open}`,
`data-state={open ? "open" : "closed"}`, `data-side={side}`를 렌더링한다. content
pointer leave 역시 wrapper 밖으로 나갈 때만 닫는다. Context가 없으면 각 part는
`Tooltip compound components must be used within Tooltip` Error를 던진다.
