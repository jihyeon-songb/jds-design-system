# Select Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 접근 가능한 조합형 단일 선택 Select를 `@jds/components`에 추가한다.

**Architecture:** `Select` Context가 controlled·uncontrolled value/open 상태와 등록된 Item을 관리한다. Trigger는 select-only combobox이고 Content는 조건부 listbox이며, Item은 Context를 통해 active·selected 상태와 선택 요청을 연결한다. 폼 제출은 `name`이 있을 때만 hidden input으로 처리한다.

**Tech Stack:** React 19, TypeScript, CSS custom properties, Vitest, Testing Library, Storybook 10

## Global Constraints

- 외부 UI·아이콘 라이브러리를 추가하지 않는다.
- 단일 문자열 값만 지원하고 `multiple`, 검색, Portal, 자동 배치는 추가하지 않는다.
- CSS의 색상·간격·크기·테두리·반경은 기존 `--jds-*` semantic token만 사용한다.
- Trigger만 tab stop이며 select-only combobox ARIA 패턴과 키보드 동작을 따른다.
- `name`이 있는 경우만 hidden input으로 폼 값을 제출하고, `required` constraint validation은 제공하지 않는다.
- 새 동작은 먼저 실패하는 컴포넌트 테스트로 명세한다.

- [ ] **Step 3: Implement the required behavior**

~~~tsx
function onTriggerKeyDown(event: KeyboardEvent<HTMLButtonElement>): void {
  if (event.key === "ArrowDown") moveActive(1)
  else if (event.key === "ArrowUp") moveActive(-1)
  else if (event.key === "Home") moveToBoundary("first")
  else if (event.key === "End") moveToBoundary("last")
  else if (event.key === "Enter" || event.key === " ") selectActiveItem()
  else if (event.key === "Escape") requestOpen(false)
}
~~~

Set Trigger `role="combobox"`, `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls`, and, while open, `aria-activedescendant`. Content is `role="listbox"` only while open. Group is `role="group"` and receives `aria-labelledby` from its SelectLabel. Item is `role="option"`, exposes `aria-selected`, and disabled Items expose `aria-disabled`.

When opening, active Item is the selected enabled Item; otherwise Enter, Space, and ArrowDown start at the first enabled Item, while ArrowUp starts at the last. Arrow navigation never wraps and skips disabled Items; Home/End use the first/last enabled Item. Implement a ref-backed 500ms case-insensitive typeahead prefix. Enter/Space selects active and closes, Escape closes unchanged, Trigger blur and an outside `pointerdown` close the list. Prevent default on enabled Item pointerdown before selection so focus stays on Trigger. Register the document listener only while open and clean it up on close/unmount.
