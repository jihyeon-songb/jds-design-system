# Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 키보드와 포인터로 즉시 전환되는 accessible controlled·uncontrolled Tabs를 `@jds/components`에 추가한다.

**Architecture:** `Tabs` owns one selected value and exposes it, an ID prefix, and the tablist ref through compound Context. Native button triggers use the tablist DOM to focus the next enabled trigger and select it; one selected `TabsContent` remains visible.

**Tech Stack:** React 19, TypeScript, native HTML button, CSS custom properties, Vitest, Testing Library, Storybook 10.

## Global Constraints

- Do not add dependencies, special hooks, or a custom activation mode.
- Reuse existing semantic CSS tokens only; do not add Tabs tokens or literal visual values.
- Support horizontal automatic activation only; exclude vertical, manual, async panels, URL state, animation, and scroll controls.
- Require exactly one of `value` and `defaultValue`; values must identify unique enabled triggers and matching content.
- Preserve the native Tab sequence and provide 24px targets, visible focus, forced-colors behavior, Storybook axe, and manual keyboard/screen-reader verification.

Create a `TabsContext` with `selectedValue`, `requestValue`, `listRef`, `tabId`, and `panelId`. `useTabsContext` must throw `Tabs compound components must be used within Tabs` when absent.

```tsx
export function Tabs({ children, className, defaultValue, onValueChange, value, ...props }: TabsProps) {
  const generatedId = useId()
  const [uncontrolledValue, setUncontrolledValue] = useState(defaultValue)
  const listRef = useRef<HTMLDivElement>(null)
  const selectedValue = value ?? uncontrolledValue
  const prefix = `jds-tabs-${generatedId}`
  function requestValue(nextValue: string): void {
    if (nextValue === selectedValue) return
    if (value === undefined) setUncontrolledValue(nextValue)
    onValueChange?.(nextValue)
  }
  return <TabsContext.Provider value={{ listRef, requestValue, selectedValue, tabId: (itemValue) => `${prefix}-tab-${encodeURIComponent(itemValue)}`, panelId: (itemValue) => `${prefix}-panel-${encodeURIComponent(itemValue)}` }}><div {...props} className={["jds-tabs", className].filter(Boolean).join(" ")} data-state="enabled">{children}</div></TabsContext.Provider>
}
```

Implement `TabsList` as a forwarded div with `role="tablist"`, `aria-orientation="horizontal"`, `jds-tabs-list`, and a callback ref that updates both `context.listRef` and the forwarded ref.

```tsx
function getEnabledTabs(list: HTMLDivElement | null): HTMLButtonElement[] {
  return Array.from(list?.querySelectorAll<HTMLButtonElement>('[role="tab"]:not(:disabled)') ?? []).filter((tab) => tab.closest('[role="tablist"]') === list)
}
```

Implement `TabsTrigger` as a forwarded native button. Set fixed `type="button"`, `role="tab"`, generated `id`, `aria-controls`, `aria-selected`, and `tabIndex={selected ? 0 : -1}`. Set `data-value` and state priority disabled, active, inactive. Call the consumer click handler before `requestValue(value)` and stop if default-prevented. In its key handler, after the consumer handler, use `getEnabledTabs`; ArrowRight/ArrowLeft wrap, Home selects index 0, End selects the final index. Prevent default only for those keys, call `requestValue(next.dataset.value!)`, then `next.focus()`.

Implement `TabsContent` as a forwarded div with fixed `role="tabpanel"`, generated `id`, `aria-labelledby`, `tabIndex={0}`, `hidden={!selected}`, `jds-tabs-content`, and active/inactive state. Do not add effects, registration, `useMemo`, `useCallback`, or `activationMode`.
