# Progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@jdsb/components`에 접근 가능한 이름과 native determinate·indeterminate 의미를 보존하는 token 기반 `Progress`를 추가한다.

**Architecture:** `Progress`는 native `<progress>` 하나를 렌더링하는 무상태 `forwardRef` 컴포넌트다. 필수 `label` prop을 root `aria-label`로 연결하고, `value`와 `max`는 수정하지 않고 native 요소에 전달한다. 새 progress semantic token은 기존 token build로 CSS custom property를 생성하며, 컴포넌트 stylesheet는 그 token과 browser progress pseudo-element만 사용한다.

**Tech Stack:** TypeScript, React 19, `@jdsb/tokens` CSS custom properties, Vitest + Testing Library, Storybook + axe.

## Global Constraints

- 새 런타임·개발 의존성을 추가하지 않는다.
- `ProgressProps`와 `Progress`를 명시적으로 export하고 `HTMLProgressElement` ref를 전달한다.
- `ProgressProps`는 `Omit<ComponentPropsWithoutRef<"progress">, "aria-label"> & { label: string }`다.
- `label`은 root `aria-label`이 된다. `aria-label` prop은 허용하지 않는다.
- `value`와 `max`를 변환·반올림·제한하지 않는다. `value`가 없으면 native indeterminate 상태를 보존한다.
- 소비자의 `className`, native progress 속성, 이벤트, ref를 보존한다.
- 기본 색상은 새 `--jdsb-color-progress-track`, `--jdsb-color-progress-indicator`만 사용한다. CSS에 시각 값 리터럴을 쓰지 않는다.
- `Progress`는 비상호작용 표시 요소다. state, effect, memoization, callback, keyboard·focus 동작, variant·size API를 추가하지 않는다.
- 모든 Storybook Story는 axe 검사 대상에 남긴다.

Create `packages/components/src/feedback/Progress.test.tsx`.

```tsx
import { createRef } from "react"
import { cleanup, fireEvent, render, screen } from "@testing-library/react"
import { afterEach, describe, expect, it, vi } from "vitest"
import { Progress as PublicProgress, type ProgressProps as PublicProgressProps } from "../index.js"
import { Progress } from "./Progress.js"

afterEach(cleanup)

describe("Progress", () => {
  it("exports Progress and its prop type from the package entry", () => {
    const props: PublicProgressProps = { label: "파일 업로드", max: 100, value: 40 }
    render(<PublicProgress {...props} data-testid="public-progress" />)

    expect(PublicProgress).toBe(Progress)
    expect(screen.getByTestId("public-progress")).toHaveClass("jdsb-progress")
  })

  it("renders a named determinate native progressbar", () => {
    render(<Progress label="파일 업로드" max={100} value={40} />)

    expect(screen.getByRole("progressbar", { name: "파일 업로드" })).toHaveValue(40)
  })

  it("keeps the native indeterminate state when value is absent", () => {
    render(<Progress label="파일 업로드 진행 중" max={100} />)

    expect(screen.getByRole("progressbar", { name: "파일 업로드 진행 중" })).not.toHaveAttribute("value")
  })

  it("forwards native props, events, and its progress ref", () => {
    const ref = createRef<HTMLProgressElement>()
    const onClick = vi.fn()
    render(<Progress className="consumer-progress" id="upload" label="업로드" onClick={onClick} ref={ref} value={1} />)

    const progress = screen.getByRole("progressbar", { name: "업로드" })
    expect(ref.current).toBe(progress)
    expect(progress).toHaveAttribute("id", "upload")
    expect(progress).toHaveClass("jdsb-progress", "consumer-progress")
    fireEvent.click(progress)
    expect(onClick).toHaveBeenCalledOnce()
  })
})
```

Create `packages/components/src/feedback/Progress.tsx`.

```tsx
import { forwardRef, type ComponentPropsWithoutRef } from "react"

export type ProgressProps = Omit<ComponentPropsWithoutRef<"progress">, "aria-label"> & {
  label: string
}

export const Progress = forwardRef<HTMLProgressElement, ProgressProps>(function Progress(
  { className, label, ...props },
  ref,
) {
  const classNames = ["jdsb-progress", className].filter(Boolean).join(" ")

  return <progress {...props} ref={ref} aria-label={label} className={classNames} />
})
```
