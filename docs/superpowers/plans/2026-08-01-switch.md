# Switch 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**목표:** Native checkbox form 동작을 보존하는 접근 가능한 네 가지 크기의 Switch를 `@jds/components`에 추가한다.

**아키텍처:** `Switch`는 `role="switch"` native checkbox 한 개다. 브라우저가 label, keyboard, form validation·submission·reset을 처리하고 React는 uncontrolled state만 native checked 상태와 동기화한다. CSS pseudo-element가 token 기반 track과 thumb를 그린다.

**기술 스택:** React 19, TypeScript, CSS custom properties, Vitest, Testing Library, Storybook 10.

## Global Constraints

- 외부 UI 라이브러리와 새 의존성을 추가하지 않는다.
- `type="checkbox"`, native form/reset/keyboard 동작을 재구현하지 않는다.
- `size`는 `"sm" | "md" | "lg" | "xl"`이고 기본값은 `"md"`다.
- 시각 값은 `@jds/tokens` CSS 변수만 사용한다.
- 공개 state 우선순위는 `disabled > invalid > checked > unchecked`다.

it("uses fixed native switch semantics", () => {

  const control = screen.getByRole("switch", { name: "마케팅 정보 수신" })
  await user.click(control)
  expect(control).toBeChecked()
  expect(control).toHaveAttribute("data-state", "checked")
  expect(new FormData(control.closest("form")!).get("marketing")).toBe("enabled")

- [ ] **3단계: 최소 구현을 작성한다**

```tsx
export type SwitchSize = "sm" | "md" | "lg" | "xl"
export type SwitchProps = Omit<ComponentPropsWithoutRef<"input">, "size" | "type"> & {
  invalid?: boolean
  size?: SwitchSize
}
```

`Checkbox.tsx`의 callback-ref/reset-listener 패턴을 그대로 사용한다. `checked !== undefined`이면 controlled로 처리하고, 그렇지 않으면 `useState(Boolean(defaultChecked))`를 쓴다. reset listener는 microtask에서 `node.checked`를 state로 복사한다. `onChange`를 먼저 호출하고 `event.defaultPrevented`가 아니면 uncontrolled state를 갱신한다. `data-state`는 disabled, invalid, checked, unchecked 순으로 계산하고 `aria-invalid`는 invalid일 때만 true로 덮어쓴다.

- [ ] **1단계: 상태 회귀 test를 추가한다**

```tsx
it("aligns state after reset and preserves controlled state", async () => {
  const user = userEvent.setup()
  render(<form><Switch aria-label="알림" defaultChecked /><button type="reset">초기화</button></form>)
  const control = screen.getByRole("switch", { name: "알림" })
  await user.click(control)
  await user.click(screen.getByRole("button", { name: "초기화" }))
  expect(control).toBeChecked()
  expect(control).toHaveAttribute("data-state", "checked")
})

it.each(["sm", "md", "lg", "xl"] as const)("exposes %s", (size) => {
  render(<Switch aria-label={`${size} 스위치`} size={size} />)
  expect(screen.getByRole("switch", { name: `${size} 스위치` })).toHaveAttribute("data-size", size)
})
```

```tsx
it("does not update uncontrolled state after a prevented change", async () => {
  const user = userEvent.setup()
  render(<Switch aria-label="알림" onChange={(event) => event.preventDefault()} />)
  const control = screen.getByRole("switch", { name: "알림" })
  await user.click(control)
  expect(control).not.toBeChecked()
  expect(control).toHaveAttribute("data-state", "unchecked")
})

it("uses native label and excludes disabled values", async () => {
  const user = userEvent.setup()
  render(<form><label htmlFor="alert">알림</label><Switch defaultChecked disabled id="alert" name="alert" value="on" /></form>)
  const control = screen.getByRole("switch", { name: "알림" })
  await user.click(screen.getByText("알림"))
  control.focus()
  await user.keyboard(" ")
  expect(control).toBeChecked()
  expect(new FormData(control.closest("form")!).has("alert")).toBe(false)
})

it("gives disabled precedence over invalid", () => {
  const { rerender } = render(<Switch aria-label="알림" checked invalid onChange={() => undefined} />)
  const control = screen.getByRole("switch", { name: "알림" })
  expect(control).toHaveAttribute("aria-invalid", "true")
  expect(control).toHaveAttribute("data-state", "invalid")
  rerender(<Switch aria-label="알림" checked disabled invalid onChange={() => undefined} />)
  expect(control).toHaveAttribute("data-state", "disabled")
})
```

- [ ] **3단계: token-only CSS와 export를 작성한다**

`.jds-switch`는 token `target-block` 높이를 가진 `appearance: none` positioned input이다. `::before`는 세로 가운데 정렬된 track, `::after`는 흰색 thumb를 렌더링한다. size별 token dimension과 thumb travel을 사용한다. checked에는 primary background, hover에는 primary hover, focus에는 `size.focus`/`color.focus.ring`, invalid에는 border outline, disabled에는 opacity, forced-colors에는 `forced-color-adjust: auto`를 사용한다. transition이나 리터럴 시각 값은 추가하지 않는다.

Register exactly:

```ts
export { Switch, type SwitchProps, type SwitchSize } from "./inputs/Switch.js"
```

```css
@import "./inputs/Switch.css";
```

Add `src/inputs/Switch.css` to `packages/components/package.json`'s `files` array.
