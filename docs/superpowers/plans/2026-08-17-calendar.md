# Calendar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@jdsb/components`에 단일 ISO 날짜를 선택하는 접근 가능한 Calendar date-grid를 추가한다.

**Architecture:** `Calendar.tsx` 한 파일에서 ISO 날짜 검증·월 계산·상태·키보드 이동을 소유한다. 날짜 칸은 native button을 사용하고 gridcell은 그 버튼을 감싼다. 기존 action·field·focus 토큰만 재사용하므로 새 토큰이나 의존성은 추가하지 않는다.

**Tech Stack:** React 19, TypeScript, native HTML/ARIA, Vitest, Testing Library, Storybook.

## Global Constraints

- DatePicker trigger, 범위·다중 선택, 시간, preset, 텍스트 날짜 파싱은 제공하지 않는다.
- 공개 `CalendarProps`는 `ComponentPropsWithoutRef<"div">`를 확장하며 `aria-label`을 필수로 한다.
- 날짜는 `YYYY-MM-DD`, 월은 `YYYY-MM`만 받고 잘못된 값 또는 `min > max`는 `RangeError`를 발생시킨다.
- `new Date("YYYY-MM-DD")`와 `toISOString()`을 사용하지 않는다.
- 스타일에는 시각 리터럴을 넣지 않고 기존 semantic token만 사용한다.
- 키보드·포커스·ARIA를 포함한 접근성 동작을 테스트하고 모든 Storybook Story의 axe 검사를 유지한다.

- [ ] **Step 4: ISO date/month helpers와 공개 타입을 구현한다.**

```tsx
export type CalendarProps = Omit<ComponentPropsWithoutRef<"div">, "children"> & {
  "aria-label": string
  defaultMonth?: string
  defaultValue?: string
  locale?: string
  max?: string
  min?: string
  month?: string
  onMonthChange?: (month: string) => void
  onValueChange?: (value: string) => void
  value?: string
}

function parseDate(value: string, name: string): Date {
  const match = /^(\d{4})-(\d{2})-(\d{2})$/.exec(value)
  if (!match) throw new RangeError(`${name} must be a YYYY-MM-DD date`)
  const date = new Date(Number(match[1]), Number(match[2]) - 1, Number(match[3]))
  if (formatDate(date) !== value) throw new RangeError(`${name} must be a valid date`)
  return date
}

function formatDate(date: Date): string {
  return [date.getFullYear(), date.getMonth() + 1, date.getDate()]
    .map((part, index) => index === 0 ? String(part).padStart(4, "0") : String(part).padStart(2, "0"))
    .join("-")
}
```

동일 파일에 `parseMonth`, `formatMonth`, `addDays`, `addMonths`, `getDaysInMonth`,
`clampDate`를 private 함수로 둔다. 모든 date 생성은 numeric constructor로 하고
local getter로 문자열화한다.

- [ ] **Step 5: controlled/uncontrolled 상태와 grid를 렌더링한다.**

```tsx
const selectedValue = value ?? uncontrolledValue
const visibleMonth = month ?? uncontrolledMonth

function requestValue(nextValue: string): void {
  if (value === undefined) setUncontrolledValue(nextValue)
  onValueChange?.(nextValue)
}

function requestMonth(nextMonth: string): void {
  if (month === undefined) setUncontrolledMonth(nextMonth)
  onMonthChange?.(nextMonth)
}
```

일요일 시작 요일 header, 이전/다음 월 button, 날짜 칸 `role="gridcell"`과 내부
`button type="button"`을 렌더링한다. 선택된 날짜 칸만 `aria-selected="true"`로
표시한다. 현재 표시 월의 선택 날짜 또는 범위 안 첫 날짜 하나에만 `tabIndex={0}`을
설정한다. min/max 밖 날짜와 전부 범위 밖인 이전/다음 월 control은 `disabled`로
설정한다.

- [ ] **Step 6: 날짜 버튼 keyboard handler와 focus 복원을 구현한다.**

```tsx
function onDayKeyDown(event: KeyboardEvent<HTMLButtonElement>, date: Date): void {
  const delta = event.key === "ArrowLeft" ? -1 : event.key === "ArrowRight" ? 1 : 0
  if (delta !== 0) {
    event.preventDefault()
    moveFocus(clampDate(addDays(date, delta), minDate, maxDate))
  }
}
```

Arrow는 하루, Home/End는 주 경계, PageUp/PageDown은 월, Shift+PageUp/PageDown은
년 단위로 이동시킨다. 이동 뒤 월이 바뀌면 `requestMonth`를 호출하고, `useEffect`로
목적 날짜 button에 focus를 복원한다. Enter/Space는 native button click으로 선택한다.
