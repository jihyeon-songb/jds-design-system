# Drawer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dialog의 접근성 동작을 재사용하는 edge-aligned modal Drawer를 제공한다.

**Architecture:** Drawer compound parts는 Dialog를 alias하고, `DrawerContent`만 side data
attribute와 class를 더하는 thin wrapper다. 크기는 Drawer component token으로, 색상과
상호작용 스타일은 기존 Dialog CSS로 제공한다.

**Tech Stack:** React 19, TypeScript, native `<dialog>`, CSS tokens, Vitest, Storybook 10.

## Global Constraints

- `pnpm`만 사용하고 의존성을 추가하지 않는다.
- native `<dialog>`와 Dialog의 focus lifecycle을 재사용하며 Portal·animation·gesture를 만들지 않는다.
- 시각 값은 token으로 제공한다.

### Task 1: Drawer API와 스타일

**Files:** Create `Drawer.tsx`, `Drawer.css`, `Drawer.test.tsx`; modify token JSON, component exports/CSS/package files.

- [ ] **Step 1: failing test를 작성하고 실행한다**

```tsx
render(<Drawer><DrawerContent aria-label="메뉴" /></Drawer>)
expect(screen.getByRole("dialog")).toHaveAttribute("data-side", "right")
```

Run: `pnpm test packages/components/src/overlays/Drawer.test.tsx`

Expected: FAIL — Drawer module과 export가 없다.

- [ ] **Step 2: Dialog wrapper와 side CSS를 구현한다**

```tsx
export const Drawer = Dialog
export const DrawerContent = forwardRef<HTMLDialogElement, DrawerContentProps>(
  ({ className, side = "right", ...props }, ref) => (
    <DialogContent {...props} className={["jds-drawer-content", className].filter(Boolean).join(" ")} data-side={side} ref={ref} />
  )
)
```

`size.drawer.inline`과 `size.drawer.block` token을 추가하고, `side`별 fixed edge panel CSS를
작성한다. public export, CSS import, published CSS file list를 갱신한다.

- [ ] **Step 3: test와 typecheck를 통과시킨다**

Run: `pnpm typecheck && pnpm test packages/components/src/overlays/Drawer.test.tsx && pnpm --filter @jds/components build`

Expected: PASS.
