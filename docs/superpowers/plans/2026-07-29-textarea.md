# Textarea Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@jdsb/components`에 native 동작과 maxLength 카운터를 갖춘 접근 가능한 Textarea를 추가한다.

**Architecture:** Textarea는 wrapper 안에 native `<textarea>`와 조건부 `<output>` 카운터를 렌더링한다. native `maxLength`가 길이 제한을 담당하고, 컴포넌트는 controlled value 또는 uncontrolled 입력 이벤트에서 카운터 길이만 계산한다. 스타일 값은 생성된 토큰 CSS 변수로만 제공하고, 패키지 CSS entrypoint가 Button과 Textarea 스타일을 함께 export한다.

**Tech Stack:** React 19, TypeScript 5, native CSS, Vitest, Testing Library, Storybook 10, pnpm workspace.

## Global Constraints

- native HTML과 표준 ARIA만 사용하고 외부 UI 라이브러리나 새 의존성을 추가하지 않는다.
- 공개 API에는 명시적 TypeScript 타입을 제공하고 ref 및 적용 가능한 native textarea 속성을 전달한다.
- 컴포넌트 CSS에는 시각 값 리터럴을 쓰지 않고 semantic/component `--jdsb-*` 토큰만 사용한다.
- `maxLength`가 있을 때만 `현재 / 최대` 카운터를 표시하며, 입력 제한은 native `maxLength`에 맡긴다.
- 자동 높이 조절, FormField API, 브라우저 기본 resize 동작 변경은 구현하지 않는다.
- WCAG 2.2 AA를 기준으로 focus-visible, keyboard, forced-colors, reduced-motion을 지원한다.
- 완료 전 `pnpm typecheck`, `pnpm test`, `pnpm build`, `pnpm lint` 및 Storybook build를 통과시킨다.

- [ ] **Step 1: 실패하는 Textarea 테스트를 작성한다**

`packages/components/src/Textarea.test.tsx`에 native props/ref, 조건부 카운터, uncontrolled 변경, controlled 변경, invalid 및 disabled/readOnly 상태를 검증하는 테스트를 작성한다.

```tsx
it("shows and updates a counter only when maxLength is set", () => {
  render(<Textarea aria-label="소개" maxLength={10} defaultValue="안녕" />)

  const control = screen.getByRole("textbox", { name: "소개" })
  expect(screen.getByText("2 / 10")).toBeInTheDocument()
  fireEvent.change(control, { target: { value: "반갑습니다" } })
  expect(screen.getByText("5 / 10")).toBeInTheDocument()
})
```

controlled case는 `value` prop 변경 시 카운터가 다시 계산되는지, no-maxLength case는 `data-slot="counter"`가 없는지 확인한다.

- [ ] **Step 3: 최소 Textarea 구현을 작성한다**

`packages/components/src/Textarea.tsx`에 다음 API와 controlled/uncontrolled 길이 계산을 구현한다.

```tsx
export type TextareaSize = "sm" | "md" | "lg"

export type TextareaProps = ComponentPropsWithoutRef<"textarea"> & {
  size?: TextareaSize
  invalid?: boolean
}

const textLength = (value: TextareaProps["value"] | TextareaProps["defaultValue"]): number =>
  String(value ?? "").length
```

`forwardRef<HTMLTextAreaElement, TextareaProps>`로 `<textarea>`를 렌더링한다. `value !== undefined`이면 `value`에서 길이를 계산하고, 그렇지 않으면 `defaultValue`로 초기화한 state를 `onChange`에서 갱신한다. 소비자 `onChange`는 항상 호출한다.

`maxLength !== undefined`일 때만 `<output data-slot="counter" aria-live="polite">{`${length} / ${maxLength}`}</output>`을 렌더링한다. `useId`로 생성한 counter ID와 기존 `aria-describedby`를 공백으로 결합한다. root와 textarea에 `data-state`를 설정하고 `invalid`일 때만 `aria-invalid="true"`를 쓴다.

`index.ts`에서 다음을 export하고 `tsconfig.json` include에 `src/Textarea.tsx`를 추가한다.

```ts
export { Textarea, type TextareaProps, type TextareaSize } from "./Textarea.js"
```
