# Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `@jdsb/components`에 접근 기술에서 숨겨지는 token 기반의 조합 가능한 `Skeleton` 프리미티브를 추가한다.

**Architecture:** `Skeleton`은 native `<span>`을 렌더링하는 무상태 `forwardRef` 컴포넌트다. 크기와 모양은 소비자가 `className` 또는 native `style`로 조합하고, 컴포넌트는 장식용 background와 기본 반경만 제공한다. 새 `color.skeleton.background` token을 source에서 빌드해 CSS 변수를 만들고 package entry·CSS entry·npm allowlist에 등록한다.

**Tech Stack:** TypeScript, React 19, `@jdsb/tokens` CSS custom properties, Vitest + Testing Library, Storybook + axe.

## Global Constraints

- 새 런타임·개발 의존성을 추가하지 않는다.
- `SkeletonProps`와 `Skeleton`을 명시적으로 export하고, root `HTMLSpanElement` ref를 전달한다.
- `SkeletonProps`는 `Omit<ComponentPropsWithoutRef<"span">, "children">`다.
- `Skeleton`은 항상 `aria-hidden="true"`이며 children, role, accessible name, variant, size, loading 상태, keyboard·focus 동작을 제공하지 않는다.
- 소비자의 `className`, native span 속성, 이벤트, ref를 보존한다. 소비자가 전달한 `aria-hidden`은 컴포넌트의 장식 계약을 바꾸지 못한다.
- 기본 배경은 새 `--jdsb-color-skeleton-background`, 기본 반경은 기존 `--jdsb-radius-control`만 사용한다. CSS에 시각 값 리터럴을 쓰지 않는다.
- 크기, 원형 모양, 배치와 로딩 영역의 `aria-busy`·accessible name은 소비자가 책임진다.
- 단순 무상태 markup만 사용한다. state, effect, memoization, callback, 동적 import를 추가하지 않는다.
- 모든 Storybook Story는 axe 검사 대상에 남긴다.

```tsx
import { createRef } from "react"
import { cleanup, fireEvent, render, screen } from "@testing-library/react"
import { afterEach, describe, expect, it, vi } from "vitest"
import {
  Skeleton as PublicSkeleton,
  type SkeletonProps as PublicSkeletonProps,
} from "../index.js"
import { Skeleton } from "./Skeleton.js"

afterEach(cleanup)

describe("Skeleton", () => {
  it("exports Skeleton and its prop type from the package entry", () => {
    const props: PublicSkeletonProps = { className: "text-placeholder" }
    render(<PublicSkeleton {...props} data-testid="public-skeleton" />)

    expect(PublicSkeleton).toBe(Skeleton)
    expect(screen.getByTestId("public-skeleton")).toHaveClass("jdsb-skeleton", "text-placeholder")
  })

  it("renders a decorative span and forces aria-hidden", () => {
    render(<Skeleton aria-hidden={false} data-testid="skeleton" />)

    const skeleton = screen.getByTestId("skeleton")
    expect(skeleton.tagName).toBe("SPAN")
    expect(skeleton).toHaveAttribute("aria-hidden", "true")
  })

  it("forwards native props, events, and its span ref", () => {
    const ref = createRef<HTMLSpanElement>()
    const onClick = vi.fn()
    render(<Skeleton className="consumer-skeleton" id="profile-name" onClick={onClick} ref={ref} data-testid="skeleton" />)

    const skeleton = screen.getByTestId("skeleton")
    expect(ref.current).toBe(skeleton)
    expect(skeleton).toHaveAttribute("id", "profile-name")
    expect(skeleton).toHaveClass("jdsb-skeleton", "consumer-skeleton")
    fireEvent.click(skeleton)
    expect(onClick).toHaveBeenCalledOnce()
  })
})
```

Create `packages/components/src/layout/Skeleton.tsx`.

```tsx
import { forwardRef, type ComponentPropsWithoutRef } from "react"

export type SkeletonProps = Omit<ComponentPropsWithoutRef<"span">, "children">

export const Skeleton = forwardRef<HTMLSpanElement, SkeletonProps>(function Skeleton(
  { className, ...props },
  ref,
) {
  const classNames = ["jdsb-skeleton", className].filter(Boolean).join(" ")

  return <span {...props} ref={ref} aria-hidden="true" className={classNames} />
})
```
